Accessibility Statement

Last Reviewed: January 1, 2025

Artevotrade LLC ("the Firm") is committed to ensuring that its website is accessible to all users, including those with disabilities. We strive to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA as our conformance target, as developed by the World Wide Web Consortium (W3C).

1. Our Conformance Target

We aim to conform to WCAG 2.1 Level AA in the design and operation of this website. WCAG 2.1 is organized around four principles:

Perceivable

Information and user interface components must be presentable in ways all users can perceive. We provide text alternatives for images and ensure sufficient color contrast.

Operable

User interface components and navigation must be operable. The website is designed to be navigable via keyboard as well as mouse or touch input.

Understandable

Information and the operation of the user interface must be understandable. We use plain language and clear navigation structures throughout.

Robust

Content must be robust enough to be interpreted by a wide variety of user agents, including assistive technologies such as screen readers.

2. Technical Accessibility Measures

The following measures have been implemented across this website to improve accessibility:

  • Semantic HTML5 elements used throughout (header, nav, main, section, footer, etc.);
  • ARIA labels applied to interactive elements where appropriate;
  • Sufficient color contrast ratios across text and background combinations;
  • All images include descriptive alt text or are marked as decorative where appropriate;
  • Focus indicators are visible for keyboard navigation;
  • Forms include associated labels for all input fields;
  • The page language is declared in the HTML lang attribute;
  • The website is designed to be responsive and functional across screen sizes and zoom levels up to 200%.

3. Known Limitations & Workarounds

While we strive for full WCAG 2.1 AA conformance, we acknowledge the following known limitations. We are actively working to address these in future updates:

Third-party embedded content

Any third-party scripts or embeds (e.g., analytics, contact integrations) may not fully conform to WCAG 2.1. We work to minimize non-conforming third-party content.

Workaround: Users may disable JavaScript or use browser accessibility extensions to bypass non-conforming third-party elements.

PDF and downloadable documents

Any downloadable documents linked from this website may not yet be fully accessible. We are progressively improving document accessibility.

Workaround: Contact us to request an accessible alternative format for any document.

Complex data tables

Some complex tables on legal pages may be challenging for screen reader users. We are reviewing table markup for improved accessibility.

Workaround: Contact us and we will provide the information in an alternative accessible format.

4. Browser and Assistive Technology Compatibility

This website is designed to be compatible with the following browsers and assistive technologies:

  • Google Chrome (latest two major versions) with NVDA or JAWS screen readers;
  • Mozilla Firefox (latest two major versions) with NVDA;
  • Apple Safari (latest two major versions) with VoiceOver on macOS and iOS;
  • Microsoft Edge (latest two major versions);
  • Mobile browsers on iOS and Android with system accessibility features enabled.
